01. Project Overview

This project explores daily digital habits using a sample dataset. It analyzes screen time, sleep hours and study hours to understand their patterns.

Python

Used to write the analysis program.

NumPy

Used for numerical calculations.

Pandas

Used to organize and analyze data.

02. Objectives

  • Analyze daily screen time.
  • Calculate average sleep duration.
  • Understand study-hour patterns.
  • Practice data analysis and visualization.

Average Screen Time

4.86 hours

Average Sleep

7 hours

Average Study Time

3 hours

In this sample, days with more screen time tend to have fewer study hours. This is an observation from a small illustrative dataset, not proof of cause.

05. Conclusion

This project demonstrates how Python, NumPy and Pandas can help analyze data. Graphs and summary statistics make daily patterns easier to understand. Real-world data is needed for stronger conclusions.
